# Branding Placeholders

Place finalized branding files here when they are available.

- `app.ico` overrides the main executable and window icon.
- `tray.ico` overrides the tray icon.
- `installer.ico` overrides the installer icon.
- `about-panel.txt` overrides the About dialog placeholder art/copy.

If these files are absent, the build falls back to `assets/icon.ico` and the
default placeholder panel so packaging still succeeds.
