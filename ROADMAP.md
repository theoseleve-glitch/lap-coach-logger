# Roadmap

## Reliability
- Automatic reconnection when iRacing or ACC restarts or drops the session
- Crash-safe recording: no data loss if the app or simulator crashes mid-session

## Data
- Import of iRacing .ibt telemetry files
- Session export (CSV)

## Testing
- Headless test suite running on Linux with recorded sample sessions
- Regression tests on telemetry parsing for both simulators

## UX
- Configurable overlays (layout, channels, units)
- Windows installer hardening and auto-update check
